# FOFA 竞赛作答

本目录保存参赛包的核心输入资料和当前作答成果。

## 目录

- `input/`：四份核心 DOCX，作为需求与题目基线。
- `output/答案-初级版.json`：100 道题的初级答案，选手名称为黄志豪。
- `output/FOFA初级答案说明.md`：关键推理、不可转换理由与待验证疑问。
- `output/FOFA竞赛核心需求确认书.docx`：从四份核心 DOCX 整理的需求确认书。

## 当前状态

- 题号数量、唯一性、顺序和参赛包编号均已通过本地结构校验。
- 当前为初级答案版本，尚未使用 FOFA 账号逐条执行查询。
- 正式提交前应优先复核说明文件中列出的地域枚举、产品标签、模糊匹配和动态指纹疑问。

> 仓库应保持私有，避免公开比赛题目和答案。
